Formulario Completo

Tu hoja de trucos definitiva para resolver cualquier integral.

1. Reglas Básicas

\[ \int k \, dx = kx + C \]
\[ \int x^n \, dx = \frac{x^{n+1}}{n+1} + C \quad (n \neq -1) \]
\[ \int \frac{1}{x} \, dx = \ln|x| + C \]
\[ \int e^x \, dx = e^x + C \]
\[ \int a^x \, dx = \frac{a^x}{\ln(a)} + C \]

2. Propiedades Algebraicas

\[ \int k \cdot f(x) \, dx = k \int f(x) \, dx \]
\[ \int [f(x) \pm g(x)] \, dx = \int f(x) \, dx \pm \int g(x) \, dx \]

3. Integrales Trigonométricas

\[ \int \sin(x) \, dx = -\cos(x) + C \]
\[ \int \cos(x) \, dx = \sin(x) + C \]
\[ \int \sec^2(x) \, dx = \tan(x) + C \]
\[ \int \csc^2(x) \, dx = -\cot(x) + C \]
\[ \int \sec(x)\tan(x) \, dx = \sec(x) + C \]
\[ \int \csc(x)\cot(x) \, dx = -\csc(x) + C \]

4. Funciones Inversas y Trigonométricas Inversas

\[ \int \frac{1}{\sqrt{1 - x^2}} \, dx = \arcsin(x) + C \]
\[ \int \frac{1}{1 + x^2} \, dx = \arctan(x) + C \]
\[ \int \frac{1}{x\sqrt{x^2 - 1}} \, dx = \text{arcsec}|x| + C \]

Nota: En todas las integrales indefinidas se asume una constante de integración \(C\).
